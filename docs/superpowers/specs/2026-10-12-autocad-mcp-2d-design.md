# AutoCAD MCP 二维绘图与教学 Skills 设计

日期：2026-10-12。目标环境：Windows、AutoCAD 2026（R25.1）、.NET 8。

## 目标与参考

让 Codex 通过本地 MCP 驱动真实 AutoCAD，按“确认尺寸 → 分图层、分阶段绘制 → 原生尺寸标注 → 读取结果复核 → 保存”完成二维工程绘图，配套可安装的 Skills 和复杂阶梯法兰教学案例。

参考用户展示的抖音视频《Codex+AutoCAD全自动工作流分享》，视频 ID 为 7648180739812468155。已查看需求拆解、分层绘图、机械结构逐步生成和精度问题说明的画面。视频没有提供可核实的 MCP 源码；本项目参考其工作流，使用已有 AI-CAD 插件实现。

已确认的设计：在现有 AutoCAD 2026 MCP 上增加直线、圆、圆弧、多段线、图层、原生尺寸和保存接口；Skills 控制阶段执行与复核；用复杂阶梯法兰完成教学验证。

## 方案与架构

采用已有 C#/.NET 插件：Codex → MCP STDIO Bridge → 当前用户命名管道 → AutoCAD 插件请求队列 → 主线程文档锁与数据库事务。沿用会话发现、协议、请求状态和批次记录，保留现有圆角四孔底板和读取工具。

另一种方案是通过 COM 执行绘图脚本。它适合已有固定案例，但会增加异步命令状态和脚本注入处理；本次采用原生 .NET 实体接口，MCP 接收结构化参数，不开放任意 Python、AutoLISP、SCR 或系统命令执行。

## MCP 接口

新增工具使用现有 Bridge 的工具注册和管道客户端：

| 工具 | 用途与输入 | 返回 |
|---|---|---|
| `cad_draw_2d` | `planJson`：请求 GUID、当前图纸指纹、单位、图层定义、实体列表。一次调用代表一个绘制阶段 | 成功状态、批次 ID、语义 ID 到实体句柄的映射、耗时和警告 |
| `cad_get_layers` | 分页读取当前图纸图层 | 名称、颜色、线型、锁定/关闭状态、下一页游标、图纸指纹 |
| `cad_get_geometry` | 读取最多 20 个指定句柄的二维几何数据 | 线端点、圆/弧中心和半径、多段线顶点与 bulge、闭合状态、原生尺寸实测值等 |
| `cad_save_drawing` | 当前图纸指纹、绝对 DWG/DXF 输出路径，至少指定一种 | 已生成的路径、文件大小和保存后的图纸指纹 |

二维实体类型为直线、圆、圆弧、多段线，以及对齐、水平/垂直、半径、直径原生尺寸。弧的输入角度使用度数，转换为 AutoCAD 的弧度。多段线顶点支持 bulge，满足圆角轮廓与长圆槽的准确表示。尺寸文字默认使用几何实测值，可附加孔数等前缀，不以手绘线条模拟尺寸。

图层随阶段计划创建。已有同名图层保留现有设置，发生设置冲突时报告错误，不悄悄改变既有图纸。线型只接受 Continuous、CENTER、HIDDEN；实际加载失败时返回明确错误。

使用 WCS 二维坐标，Z=0。计划单位必须与活动图纸一致；未定义单位、只读图纸或图纸指纹变化时拒绝写入。每个阶段使用独立请求 GUID；同一个请求的重试必须保持原计划，同 GUID 不同参数报冲突。超时先查询现有 `cad_get_request_status`，避免重复创建。

每次计划最多 500 个实体、32 个图层，每条多段线最多 256 个顶点；所有数值必须有限，半径和有效尺寸为正。校验错误在数据库写入前返回；运行时失败回滚本阶段事务。沿用现有批次撤销规则，只撤销最近且未被用户改动的 AI 批次。

## 保存与图纸边界

教学演示使用新空白毫米图纸。操作现有图纸时先明确任务范围，并优先在副本中演示。保存接口只生成新的 DWG/DXF，拒绝覆盖已有路径和当前源文件；不修改用户的其他图纸。

保存成功需要检查文件存在且非空。教学验证另外执行保存重开、几何尺寸检查和预览检查，不能仅凭工具返回“成功”宣布图纸正确。DWG/DXF 使用本机 AutoCAD 实际支持的格式，不虚构支持其他 CAD 版本。

## 配套 Skills 与教学材料

交付连接与二维绘图 Skill，以及工程图复核/教学 Skill。技能说明分别负责环境与工具调用、阶段拆解、几何复核和录屏提示，使用真实工具名和经过验证的参数样例。提供可复制的接入配置与安装说明，保留用户已有 Codex 配置；提示重载 MCP 后检查工具列表。

教学案例沿用已有阶梯法兰参数：外形 220×160 mm、20 处 R8 圆角、中央孔 Ø60、Ø90 节圆上均布 6×Ø10 孔、4×Ø9 安装孔、两个 30×12 长圆槽。分为轮廓、孔槽与中心线、原生尺寸三个阶段。案例通过新 MCP 路线生成；已有独立 LSP 仅作为对照，不冒充 MCP 绘图证据。

交付包括源码、MCP 可执行包、Skills、安装与连接说明、阶段 JSON/提示词、真实 DWG/DXF、PNG 预览和验证记录。本次不制作配音或最终教学视频，不加入企业部署、收费系统或任意三维模型生成。

## 验证与验收

1. 保持现有 86 项单元测试通过。新增校验测试覆盖非法几何、重复语义 ID、单位/指纹不匹配、非法保存路径、同请求不同参数和结构化计划序列化。
2. 实际运行 MCP STDIO 客户端，验证初始化、工具列表、错误返回，以及调用连接、分阶段绘图、几何/尺寸读取和保存。
3. 在本机 AutoCAD 2026 生成阶梯法兰，检查闭合轮廓、圆角和孔槽几何、原生尺寸类型与数值，确认重试不会重复生成实体。
4. 保存并重新打开 DWG，读取实体/尺寸证据；校核 DXF 并查看 PNG，发现错误后修正再验证。
5. 验证 Skill 格式和安装配置。打包时不包含 Autodesk SDK、用户凭据、会话令牌、Git 内部文件或无关项目文件。

只有以上实际检查完成后，报告“已实现并验证”。若某项失败，交付源码和已有证据，并明确未通过的项目。
