# Codex 调用 AutoCAD：约5分钟教学演示稿

定位：给第一次接触 AI 绘图的观众看清准备、操作和复核。时间为录制编排参考，AI等待时间可剪辑加速；不是工具运行时间承诺。按实际结果口播，未通过的检查不念成已通过。

## 录制前

安装 AutoCAD 2026、AI-CAD MCP 和两套 Skills，刷新连接。左右展示 Codex 和 AutoCAD，先打开参考成图展示，然后新建 acadiso.dwt 空白图。打开工具包根目录，准备 `examples/mcp-stepped-flange/prompts.txt`。分段发送提示词，阶段间手动缩放检查。

## 0:00–0:30 成图与目标

**口播：**
“这张图有阶梯外形、二十处圆角、十一处圆孔、两处长圆槽，还有二十五个尺寸。今天我们用 Codex 调用 AutoCAD，把它分三步画出来。你要学会的是：怎样把尺寸交代清楚，怎样让 AI 分步执行，以及怎样确认它真的画对了。”

**画面：** 展示参考成图，放大孔槽与原生尺寸，随后切到空白图。

## 0:30–1:10 先准备什么

**口播：**
“先准备能正常使用的 AutoCAD 2026，以及 Codex。本次还配一个 MCP 连接工具，让 Codex 能调用本机 CAD；两份 Skills 则告诉它怎样拆分任务和检查图纸。安装后先检查连接，告诉我们当前是哪张图、单位是什么。这里用毫米，所有坐标都落在同一个二维平面。”

**画面：** 在 CAD 命令行显示 AICADSTATUS；发送准备提示词，显示 health/context 的实际图纸和单位。安装过程可单独录补充教程。

## 1:10–2:00 第一步：轮廓

**口播：**
“先把外轮廓画稳。总宽二百二十，总高一百六十，二十处圆角都是 R8。我们让它只做第一阶段，完成后停下来检查。这样出现问题，就能定位到这一段。你看，工具返回的是实际对象句柄，我们还能读回闭合状态和圆角数据。”

**画面：** 发送第一段提示词；创建完成后在 CAD 全图缩放，展示闭合轮廓与圆角复核。思考等待可倍速，最终结果留正常速度。

## 2:00–2:55 第二步：孔槽和中心线

**口播：**
“第二步补孔和槽。中间是直径六十的孔，直径九十的节圆上均布六个直径十的孔，再加四个直径九的安装孔，两边是三十乘十二的长圆槽。这里有个容易忽略的地方：节圆是定位参考线，不能当作第十二个孔。检查时要读每个圆的图层、中心和半径。”

**画面：** 发送第二段提示词；放大节圆与六孔，再展示两个槽。结果里突出实际11孔、槽30×12。

## 2:55–3:50 第三步：原生尺寸

**口播：**
“第三步加尺寸。它创建的是 CAD 原生尺寸对象，你可以选中查看属性。我们先核对总宽二百二十、总高一百六十，再看孔径、槽长宽和圆角。原生尺寸按定义点测量；以后修改几何，也要同步检查标注，不能只看数字摆在旁边就算完成。”

**画面：** 发送第三段提示词，显示25个尺寸；点选总宽和孔径尺寸，展示 CAD 属性或 MCP measurement。

## 3:50–4:40 读回检查，保存图纸

**口播：**
“成图之后，我们再让 Codex 把实际几何读回来。外形要闭合，圆角半径要对，孔的位置和大小要对，槽的总长总宽也要对。确认后保存新的 DWG 和 DXF。文件生成以后再打开一次，读回对象和尺寸，确认内容确实保存下来。”

**画面：** 发最后提示词，展示主要测量值与真实导出路径。打开导出的 DWG，再读回66对象和25尺寸。

## 4:40–5:00 收尾

**口播：**
“这一套的关键，是把尺寸变成可以执行、可以检查的任务。你可以先照着这张阶梯法兰练一次：轮廓、孔槽、标注，完成一段就复核一段。工具包里放好了三段提示词、参考图和检查结果，下一次再换成你自己的尺寸。”

**画面：** 完整成图与工具包目录，保留最后画面两到三秒。
